# Media de Fritz

Copia aquí las fotos/audios desde iCloud Drive.

## Carpetas
- `shows/` — fotos de shows (jpg/png/webp)
- `covers/` — portadas de sets/beats/remix
- `audio/` — MP3 de sets y beats
- `remixes/` — archivos descargables
- `beats/` — stems o previews de beats
- `shop/` — fotos de merch

## Flujo
1. En Finder: iCloud Drive → selecciona archivos
2. Cópialos a esta carpeta (o arrástralos en Cursor)
3. En `/admin` registra el ítem con la ruta `/media/...`
4. Haz commit + deploy para publicar

## Videos
No subas videos pesados aquí. Usa YouTube y pega el ID en el panel.
